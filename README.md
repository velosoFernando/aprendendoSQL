## 📚 Sobre o Curso

Durante o curso explorei, de forma prática, conceitos essenciais de SQL para trabalhar com bancos relacionais: consultas, filtragem, ordenação, manipulação e análise de dados.

Trabalhei usando o banco **AdventureWorks2017**, executei desafios e exercitei situações reais.  
Para melhorar a visualização, transformei arquivos `.txt` em `.sql`, deixando tudo **muito mais bonito e funcional** para leitura e execução.

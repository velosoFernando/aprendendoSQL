## 📚 Sobre o Curso

Durante o curso explorei na prática os fundamentos de SQL, entendendo como bancos relacionais funcionam e como consultas podem transformar dados em informações úteis.

Trabalhei utilizando o banco **AdventureWorks2017**, realizei desafios, escrevi várias queries e analisei cenários reais.

Também converti arquivos `.txt` para `.sql` para deixar a leitura mais confortável, organizada e fácil de executar.
